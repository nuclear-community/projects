# 🛠️ projects

**The community project incubator — propose an idea, find teammates, and build open-source nuclear tools together.**

Part of the [Nuclear Science & Engineering Community](https://github.com/nuclear-community). Looking to *contribute* rather than start something? Skip to [Current projects](#current-projects).

## Why an incubator?

Learning nuclear science is one thing; **using it** is another. A small, real project — a decay-chain visualizer, a shielding calculator, a study tool — cements knowledge, builds a portfolio, and produces something the community keeps using. This repo is where those projects are proposed, discussed, and launched.

## How it works

```
💡 Idea → 📋 Proposal → 🥚 Incubating → 🐣 Active project → ✅ Maintained / 🏁 Completed
```

1. **💡 Idea** — browse [`ideas/`](ideas/) or add your own (a short markdown stub is enough). React with 👍 on issues/discussions to signal interest.
2. **📋 Proposal** — when an idea has interest, open a proposal using the [`PROPOSAL_TEMPLATE.md`](PROPOSAL_TEMPLATE.md): what it is, who it's for, rough scope, skills needed.
3. **🥚 Incubating** — the proposal lives here, gathers a team (2+ people), and defines a first milestone. Incubation has a **3-month pulse check**: projects with no activity get gently archived — that's healthy, not a failure.
4. **🐣 Active project** — once it has a working skeleton, it moves to its own repository under the org, listed in [Current projects](#current-projects) below.
5. **✅ / 🏁** — projects stabilize under maintainers, or complete and get archived with a writeup.

## Ground rules

- **Open source, always** — MIT for code, CC BY-SA 4.0 for content, matching the org defaults.
- **Small and finishable** — a finished 200-line tool beats an abandoned platform. Scope ruthlessly.
- **Safety boundary** — educational tools only; nothing that provides operational guidance for handling radioactive materials.
- **Two people minimum** to leave incubation — projects need a bus factor > 1.
- **Be kind** — the [code of conduct](https://github.com/nuclear-community/.github/blob/main/CODE_OF_CONDUCT.md) applies everywhere.
